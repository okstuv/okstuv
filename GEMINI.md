# Project Context: OK Stuv

This repository is located in the home directory (`~/okstuv`). Which publishes to https://okstuv.com.
It is a static site portfolio connected to GitHub repo (https://github.com/okstuv/okstuv) and deployed via Cloudflare Pages.

## Core Instructions
- When starting a session, analyze the current state of the repository (files, git status, etc.).
- Adhere to the established "vibe coding" workflow: pure HTML/CSS/JS, no heavy frameworks.
- Ensure all navigation remains consistent across all pages.
- Automatically stage, commit, and push changes to trigger Cloudflare deployments when requested.
