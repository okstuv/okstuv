# OK Stuv

OK Stuv is a static website portfolio and project hub, showcasing DIY projects, games, and tools.

## Tech Stack & Architecture

- **Frontend:** Pure HTML5, CSS3, and JavaScript. No heavy frameworks, keeping it lightweight and fast.
- **Version Control:** [GitHub](https://github.com/okstuv/okstuv) for source control and collaboration.
- **Hosting & Deployment:** [Cloudflare Pages](https://pages.cloudflare.com/), providing global edge delivery and automated CI/CD.
- **Editing & Development:** Driven by **Gemini CLI**.

## Vibe Coding with Gemini CLI

This project leverages "vibe coding" to bridge the gap between ideas and production. Changes can be made **automagically with vibe coding in Gemini CLI**, taking updates from the initial idea stage to being fully version-controlled on GitHub and deployed to the live site via Cloudflare Pages compute—all as a static website hosted for free.
